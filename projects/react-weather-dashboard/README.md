# React Weather Dashboard

A responsive weather dashboard demonstrating API-driven React UI, search, asynchronous data handling, and reusable display components.

## Tech Stack
- React
- JavaScript (ES6+)
- Vite
- REST API / Fetch
- CSS3

## Features
- Search weather by city
- Current temperature and conditions
- Humidity, wind, pressure, and visibility details
- Loading and error states
- Recent search support
- Responsive weather cards and layout

## Run locally
```bash
npm install
npm run dev
```

> Add your weather API configuration before connecting the live provider.
