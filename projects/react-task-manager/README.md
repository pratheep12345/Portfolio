# React Task Manager

A practical React task-management application demonstrating component design, CRUD operations, filtering, search, and browser persistence.

## Tech Stack
- React
- JavaScript (ES6+)
- Vite
- CSS3
- LocalStorage

## Features
- Create, edit, complete, and delete tasks
- Todo / In Progress / Completed workflow
- Search tasks by title
- Filter by status and priority
- Persistent data using LocalStorage
- Empty states and form validation
- Responsive UI

## Run locally
```bash
npm install
npm run dev
```
