# React E-Commerce Dashboard

A recruiter-ready React project demonstrating API integration, reusable components, search, category filtering, cart state, loading states, error handling, and responsive UI.

## Tech Stack
- React
- JavaScript (ES6+)
- Vite
- REST API / Fetch
- CSS3
- Local state with React hooks

## Features
- Product listing from Fake Store API
- Search products by title
- Filter by category
- Sort by price and rating
- Add/remove products from cart
- Cart quantity controls and total calculation
- Loading and API error states
- Responsive desktop/mobile layout

## Run locally
```bash
npm install
npm run dev
```
